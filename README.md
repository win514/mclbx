# mclbx

让《我的世界》Java 版联机不受网络环境限制：房主不必进路由器后台，玩家不必安装任何东西。

Minecraft Java 版的联机要求建立一条从玩家到房主游戏进程的通道。家庭网络通常处在 NAT 之后、没有可用的公网地址，通道因此建不起来。mclbx 提供三种打通方式，并负责它们之间的选择与切换。

| 入口 | 玩家需要做什么 | 适用条件 |
| --- | --- | --- |
| 公网入口 | 游戏内「多人游戏 → 直接连接」填入地址 | 房主有可被外部访问的地址（公网 IPv6，或自动端口映射成功） |
| 软件入口 | 安装本工具后填入房主给的链接或房间码 | 双方网络都不理想；配置了中继服务器时，直连失败会自动改用中继 |
| 中继转发 | 同上，或使用中继提供的地址 | 公网 IPv6 与自动端口映射都不可用时的兜底方案 |

同一个局域网内不需要本工具：原版「对局域网开放」会向局域网广播，同网段的玩家在多人游戏列表里直接就能看到房间。

## 它不做什么

- 不支持基岩版。基岩版是另一套走 UDP 的协议，端口（默认 19132）、握手与加密都与本工具承载的 TCP 协议不同。
- 不修改游戏本体，不注入进程，不要求安装 mod 或联机插件。
- 不修改注册表，不改动网卡、路由表和 DNS 设置。
- 除「入站规则」这一项外不改动系统防火墙，且该项需用户主动执行，只放行指定端口。
- 不收集、不上传任何数据，界面服务只监听本机。

## 开始使用

本仓库不含预编译产物（`dist/` 与 `mclbx.exe` 已在 `.gitignore` 中排除），请自行构建。

房主两步：

1. 进入世界后按 `Esc → 对局域网开放`，记下显示的端口号（通常为 25565）。世界未开启时没有可转发的端口。
2. 创建房间并发送邀请。房间码留空时自动生成 6 位，端口填写上一步记下的值，点击「创建房间」，再点「复制邀请」，把整段邀请文本发给玩家。

玩家两步：

1. 未安装本工具：在「多人游戏 → 直接连接」粘贴房主给的地址并回车；必要时请房主把玩家名加入白名单。
2. 已安装本工具：点「加入房间」，粘贴整段邀请文本，点「连接」。地址与房间码会自动提取。

命令行等价写法：

```powershell
# 房主：同时开启公网入口与软件入口；房间码留空则自动生成
mclbx room --port 25565 --room abc123

# 玩家：填入房主输出的信令地址与房间码
mclbx join --host [2408:xxxx::1]:8090 --room abc123
```

## 环境体检与选择

打开界面时会自动做一次体检，给出四项结论，不支持的连接方式会在界面上置灰并说明原因。命令行对应 `mclbx doctor`。

| 结论项 | 含义 |
| --- | --- |
| 公网 IPv6 | 本机是否具备可被外部直接访问的 IPv6 地址；可用时联机方式最简，玩家侧也需具备 IPv6 出口 |
| NAT 类型 | 全锥形 / 受限锥形 / 端口受限锥形 / 对称型 / 未知；对称型几乎无法直连，应直接使用中继 |
| 自动端口映射 | 路由器是否响应 UPnP、NAT-PMP 或 PCP；任一可用即可自动开端口 |
| 游戏端口 | 默认 25565 是否空闲 |

选择规则：公网 IPv6 可用就用公网入口；IPv6 不可用但能自动端口映射就用直连模式；两者都不可用（含对称型 NAT）直接用中继转发。

## 构建

需要 Go 1.24 或更高版本。项目是单个 Go 包，没有代码生成步骤。

```powershell
git clone https://github.com/win514/mclbx.git
cd mclbx
go build -o mclbx.exe .
```

版本号内置为占位值，构建时可注入：

```powershell
go build -ldflags "-X main.version=mclbx 1.74" -o mclbx.exe .
```

非 Windows 平台可以编译，各平台相关文件都有 `*_other.go` 空实现，但原生界面仅 Windows 可用：

```powershell
$env:GOOS='windows'; $env:GOARCH='amd64'; go build -o dist/mclbx-win64.exe .
$env:GOOS='linux';   $env:GOARCH='arm64'; go build -o dist/mclbx-linux-arm64 .
```

仓库里另有几份构建输入，都在需要时自动生效：

| 文件 | 作用 |
| --- | --- |
| `rsrc_windows_*.syso` | 图标与 Windows 清单等资源，Go 按目标平台自动选用同名文件 |
| `WebView2Loader.dll` | 网页版界面所需的加载器，经 `//go:embed` 内嵌进 exe，首次运行时解出 |
| `manual.html` | 使用说明书，内嵌进 exe 并由界面的「说明书」页展示 |

## 界面实现不在本仓库

`frontend/` 里只有一份说明文件。界面实现（`gui.html`、`gui.css`、`gui.js`）不随本仓库提供；构建时把它们放进 `frontend/` 即可经 `//go:embed` 内嵌，未放入时程序的 `/` 页显示一张占位说明页，`/assets/` 下的资源与接口仍然可用。

本程序只渲染页面骨架、托管界面文件并提供接口，不参与页面表现与动画。界面默认使用网页版（WebView2），加 `--native` 切换到 Windows 原生控件界面，内存占用明显更低；WebView2 运行时缺失时自动改用系统浏览器打开。

## 命令行

全部界面操作都有等价命令。`mclbx help` 输出完整帮助，`mclbx <命令> help` 查看单个命令的参数。

| 分组 | 命令 | 用途 |
| --- | --- | --- |
| 环境检测 | `doctor` | 环境体检：给出可用的连接方式与下一步命令 |
| 环境检测 | `probe` | 路况诊断：全球 IPv6、IPv4 公网映射、NAT 行为、自动端口映射 |
| 环境检测 | `diag` | 导出诊断包：版本、系统与网卡、体检结论、最近一次日志 |
| 房主 | `room` | 同时开启公网入口与软件入口 |
| 房主 | `expose` | 只开启公网入口 |
| 房主 | `ice host` | 通过 ICE 建立直连通道，并在其上承载 TCP 隧道 |
| 玩家 | `join` | 以软件方式进入房间；`--relay` 可替其他玩家中继转发 |
| 玩家 | `ice guest` | 与 `ice host` 配对，两端参数需一致 |
| 排查 | `verify` | 按真实客户端顺序校验地址，逐步骤报告结果 |
| 排查 | `relaycheck` | 校验中继链接，指出失败所在步骤 |
| 排查 | `punch` | 端口盲扫：仅诊断双对称 NAT 下是否存在可打穿的路径 |
| 排查 | `ping` | 按游戏协议查询目标，返回版本号与在线人数 |
| 排查 | `firewall` | Windows 入站规则：放行本程序与指定端口 |
| 排查 | `natmap` | 通过 UPnP / NAT-PMP / PCP 建立自动端口映射 |
| 排查 | `slpfake` | 假服务端：只应答服务器列表查询，用于确认客户端实际连到哪个端口 |
| 中继服务 | `relaybox` | 将本机作为中继服务，开启 UDP 中继、TCP 中继转发与信令信箱 |
| 中继服务 | `stun` | 启动 STUN / TURN 服务端 |
| 中继服务 | `relay` | TCP 中继转发；UDP 不可用时使用 |
| 中继服务 | `tcptunnel host\|guest` | TCP 兜底通道两端，双方均主动连接中继 |
| 中继服务 | `mailbox` | 运行信令信箱服务，为两端交换连接信息 |
| DNS | `dns local` | 启动本地 DNS，把短名称映射到本机地址与端口 |
| DNS | `dns publish` | 把同一组记录写入公网 DDNS，默认只打印、不写入 |
| 其他 | `gui` | 打开图形界面；已有实例时把窗口置于前台 |
| 其他 | `profile [档位]` | 列出暴露档位；给档位则打印它展开成的命令 |
| 其他 | `forget` | 清除界面记住的输入，下次打开恢复默认值 |
| 其他 | `help` | 显示帮助 |

### 中继服务器

房主可以填一个链接，作为直连失败时的兜底通道。所有接受该参数的位置都写作 `--relay-server <链接>`，多个链接用逗号分隔、按顺序尝试。

```text
turn:用户:密码@主机:3478      TURN 服务器；自建优先，商用 TURN 写法相同
turn:主机:3478                账号另行提供：--relay-user / --relay-pass
turns:主机:5349               TURN over TLS
turn:主机:3478?secret=密钥     使用 REST 临时凭据，客户端按共享密钥计算 HMAC 密码
tcp:主机:8090                 仅使用 TCP 的中继，即 mclbx relay
主机:端口                      未知类型：先按 TURN 使用，兜底时按 TCP 使用
mclbx://主机?turn=3478&tcp=8090&sig=8090&room=abc123&user=u&pass=p
                              一条链接包含中继、信令与房间码
```

环境变量 `MCLBX_RELAY` 与 `MCLBX_TURN` 同样有效；启动日志会输出「中继服务器：」一行，便于确认配置是否生效。手写不带账号的写法时才需要 `--relay-user` / `--relay-pass`。校验链接可用 `mclbx relaycheck <链接>`；没有现成中继时，可用 `mclbx relaybox` 把本机作为中继服务，它输出的链接已包含账号。

### 暴露档位

档位把「门槛、中继、系统设置」这些默认值收拢成一次选择，展开成一串现有参数，不引入新链路。

| 档位 | 名称 | 展开结果 | 代价 |
| --- | --- | --- | --- |
| P0 | 仅内网 | 不起入口 | 外部玩家无法连接 |
| P1 | 公开直连 | `expose` + raw 地址 + 关闭门槛 | 房主地址会出现在分享内容里，且没有门槛 |
| P2 | 私密直连 | `expose` + dns 地址 + 房间码门槛 | 房主地址仍会出现，仅持房间码的玩家可进入 |
| P3 | 隐藏房主 | `room` + dns 地址 + 房间码 + 指定中继 | 需要一台非房主机的机器当中继 |
| P4 | 受管环境 | `expose` + dns 地址 + 房间码 + 关闭自动端口映射 | 不自动映射、不写防火墙规则 |

`mclbx profile` 列出全部档位，`mclbx profile P2` 打印这一档展开成的命令。

## 端口与数据目录

| 项目 | 取值 |
| --- | --- |
| 程序本体 | 单个可执行文件，无需安装，仅依赖系统库 |
| 运行数据 | 默认在 exe 同级的 `mclbx-data`，同级不可写时退到 `%LOCALAPPDATA%\mclbx`：配置 `config.json`、日志 `gui.log` 与背景音乐 `music` |
| 界面服务 | 默认 `127.0.0.1:19870`，仅绑定本机 |
| Minecraft 默认端口 | `25565`（Java 版） |
| 本工具入站端口 | 两个：游戏端口（公网入口）与信令端口 `8090`（软件入口，可用 `--signal` 改） |
| 防火墙规则名 | `mclbx-tcp-<端口>` 与 `mclbx-udp-<端口>` |

## 权限与安全

程序默认以管理员身份启动，在打开界面时申请一次权限；提权不会让直连、自动端口映射或中继更容易成功，这些在普通权限下即可完成。用 `--no-elevate` 或环境变量 `MCLBX_NO_ELEVATE=1` 可关闭默认提权，拒绝授权时程序照常运行，只有「入站规则」那一步会再次申请。

入站规则只针对本程序与指定端口，规则名以 `mclbx-` 开头，可用同一操作删除，不影响其它规则与防火墙开关。由于公网入口使用游戏端口、软件入口另需信令端口 8090，只放行前者会出现「未安装工具的玩家能进、已安装的反而不行」；命令行一次放行两个即可：

```powershell
mclbx firewall --port 25565,8090
```

软件入口的每条连接都做一次身份绑定：两端各自生成自签证书并交换 SHA-256 指纹，随后在专用流上完成一次挑战-应答校验，校验通过且客户机回执确认后通道才算建立。绑定完成后两端各显示一个安全码，比对一致即可排除中间人。

程序没有代码签名，首次运行会申请管理员权限，因此可能被 SmartScreen 或安全软件拦下；它完全离线运行，可以断网验证，删除文件即可完全清除。

中继转发的流量会经过中继所在的机器，为保障连通性采用明文传输，房间码是唯一门槛，因此中继转发与 TCP 兜底通道都只建议作为最后手段。

## 外部依赖

默认会用到两处公共设施，都可以不用：

| 服务 | 用途 | 不用它会怎样 |
| --- | --- | --- |
| `stun.miwifi.com`、`stun.hitv.com` | 探测本机的公网映射，默认开启 | 加 `--stun=false` 即可完全不用，代价是跨网络直连基本不可用；可用环境变量 `MCLBX_STUN` 换成其他服务 |
| `sslip.io` | 「公网入口（域名）」使用的公共通配域名后缀 | 改用 IPv6 字面量模式即可不用 |
| `dynv6.com` | `dns publish` 把短名称写进公网 DNS（需自备域名） | 默认只打印、不写入；该路径按官方接口文档实现，未在真实账号上实测过，目前也只支持这一家 |
